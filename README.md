# 🚀 CodeQuest — Gamified Coding Learning Platform

CodeQuest is a gamified coding learning platform designed to make learning programming more interactive, engaging, and rewarding. It combines coding challenges, structured learning paths, progress tracking, achievements, leaderboards, and an AI Tutor interface into a single platform.

The goal is to turn coding practice into an engaging learning experience through XP, levels, streaks, achievements, and interactive challenges.

## ✨ Features

- **Interactive Dashboard** — Track coding progress, XP, level, streaks, and daily goals.
- **Learning Paths** — Explore structured programming learning paths and lessons.
- **Coding Challenges** — Practice programming through challenges categorized by difficulty.
- **Code Workspace** — Write and practice code in an integrated coding environment.
- **AI Tutor** — AI tutor interface designed to assist learners with programming concepts.
- **Leaderboard** — Compare progress and compete with other learners.
- **Achievements** — Unlock achievements and rewards for learning milestones.
- **Analytics** — Visualize coding progress, activity, and performance.
- **User Profiles** — Track personal learning information and progress.
- **Demo Authentication** — Firebase Authentication with restricted demo account access.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/vedayeminedi/CodeQuest.git
```

Navigate to the project directory:

```bash
cd CodeQuest
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal to access CodeQuest.
